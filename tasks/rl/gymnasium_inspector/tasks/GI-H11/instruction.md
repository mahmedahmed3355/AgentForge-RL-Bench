# GI-H11 — Unseen Parameter Composition

You are given a configuration whose parameter combination may not match
previously seen configurations.

Use the legitimate Inspector-visible state and constraints to derive the
invariant rule.

Required sequence:

1. Inspect the parameters and public state.
2. Derive the rule from the public constraints.
3. Plan an action consistent with the derived rule.
4. Execute the resulting configuration without violating the constraint.
5. Verify the final state before finishing.

Do not rely on memorized configuration patterns.

The terminal state is valid only when the result is consistent with the
public invariant and all required conditions have been satisfied.
